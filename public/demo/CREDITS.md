# Demo imagery — sources and licences

The photographs in this folder illustrate the demo professionals seeded by
`npm run test:seed` (see `docs/TEST-ACCOUNTS.md`). They are placeholders for
development and demo footage, and none of them depicts the professional whose
profile it appears on.

Every image was found through [Openverse](https://openverse.org) with the
licence filter set to **CC0** and **Public Domain Mark** only — dedicated to
the public domain, free to use commercially, no attribution required. The
sources are recorded anyway, so any image can be traced or swapped.

Each one was looked at before it was copied here. Work-focused shots were
chosen on purpose: equipment, hands, stages, food, crowds from behind — no
identifiable faces.

`driver-dwayne.svg` is an original placeholder avatar, not a photograph.
